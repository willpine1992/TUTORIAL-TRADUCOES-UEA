# Guia de Traduções do Site · PROPESP/UEA

Tutorial em formato de revista para a equipe PROPESP: como traduzir as páginas do site para inglês e espanhol no WPML (Advanced Translation Editor), da lista de tarefas até a página publicada, com o exemplo real da página *Apresentação Internacionalização*.

## Como atualizar

1. Edite o `index.html` (é a fonte única: versão web e PDF).
2. Rode `zsh render.sh` para regerar o PDF a partir do HTML (Chrome headless).
3. `git add -A && git commit -m "..." && git push origin main && git push inter main` — o GitHub Pages publica em ~1 minuto em cada endereço.
